# Data flow

Guest submissions, notes, scores, feedback, and rubric snapshots are stored in IndexedDB. The v1 localStorage record is imported once and a recovery copy is mirrored locally. Before a grading request leaves the browser, **Send submission code to AI** controls whether code is included, anonymization replaces known student names with S1, S2, etc., and the identifier setting strips emails and explicitly labelled student/user IDs. The roster mapping is kept in the browser; anonymous labels in generated feedback are restored locally. Turning off anonymization includes the student's display name in the request. Turning off code sharing omits code from the request entirely.

PDF/image rubric extraction sends the selected document to Gemini. Insight polishing sends aggregate class statistics and redacted issue examples, without submission code or student names. Feedback translation sends the current feedback draft to Gemini only after the grader requests translation; known names and configured identifiers are protected first, while score values and code identifiers are replaced with verified placeholders and restored locally. The original and translation are shown side by side, and only explicit confirmation replaces the draft. Offline mode disables translation. Offline grading does not send grading data to an external AI provider. Requests still pass through this app's local server. Review Google's Gemini API data-use terms before enabling AI for real student work.

Offline scoring uses the built-in rules. Its grading request reaches only this TalkGrade server, not an external AI provider. With `TEAM_MODE=1`, SQLite stores team accounts and grading records and `/s/:token` presents read-only student feedback links. Team operations are not yet available from the guest browser UI.
